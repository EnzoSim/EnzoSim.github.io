# enzosimier.com

Personal site for Enzo Simier. The editable source lives in `react-site/`; the repository root contains the static GitHub Pages build.

## Content ownership

- English editorial copy: `react-site/src/content/en.js`
- Shared URLs, image metadata, and the dated FDA snapshot: `react-site/src/content/shared.js`
- Poseidon network model: `/poseidon/index.html` is a hand-written page, not built by Vite: the dashboard (hosted on Railway) full screen in a frame, with the market note PDF and the link-preview image next to it. It is unlisted: not linked from the site, not in the sitemap, `noindex`.
- Altitude demand-planning case study: `/altitude/index.html` follows the same pattern as `/poseidon/`: a hand-written page that frames the dashboard hosted on Railway, with its link-preview image next to it. Unlisted: not linked from the site, not in the sitemap, `noindex`.
- Placement note, « Placer 900 000 € »: `/placements/index.html` is a self-contained page in French, not built by Vite, set on the programme of the two guides in Projects (twelve 64 px columns with 32 px gutters, the same grid switch, light theme only, fonts from Google Fonts, no images). Visual first: a cover with contents, then twelve short chapters made of tiles, a scorecard of the three options, token equations, the dashboard guide's stages for its charts (lines, stacked bars, waterfalls) and two simulators, and inline SVG diagrams of the mechanisms (the life-insurance envelope, French against Luxembourg protection, one contract against two for the children). Figures dated 3 October 2026, for a married couple in their mid-50s. Its calculation engine (`Fin`) and chart functions (`Viz`) are inline scripts at the end of the file, so every figure is drawn from the same numbers as the text. Edit it in place. Unlisted: not linked from the site, not in the sitemap, `noindex`.
- Dashboard design study guide, « Learn dashboard design with me »: a cover and nine chapter pages under `/projects/dashboard-design-guide/`, with a French edition under `/projects/dashboard-design-guide/fr/` (chapter folders have French names there). The pages are generated, not built by Vite: run `node scripts/build-guide.mjs` from `react-site/` after editing `react-site/src/guide/` (copy in `content/en.js`, `content/fr.js` and the `*.en.json` / `*.fr.json` files beside them; shared data in `data/`; styles and scripts in `runtime/`; the people, research and dashboards chapters in `build-extra.mjs`). The design source is the Paper file « Learn dashboard design with me — the guide ». The figures are general and grey: `assets/fig2.js` draws the cover dashboard, every rule's model and the system's Tune (one file per figure in `react-site/src/guide/runtime/fig2/`, on a shared core described in its README), `assets/research.js` draws the charts of chapter 6, and `assets/figures.js` keeps the people timeline; portraits and dashboard captures are committed under `assets/img/`, and every photograph is credited in chapter 9. The guide keeps its own grid of twelve 64 px columns with 32 px gutters (1120 px; 1000 px under a 1200 px window; one fluid column under 1080 px). Five dashboard case studies in chapter 7 are private and are described without the client's name; the Water capture has every figure masked, at the municipalities' request. The rules point to them with one line each; the rules' own figures use no client data. The chapters run on as one scroll: each page holds one chapter block (`.chap`) that names the next, and `assets/page.js` fetches and appends it near the end, then moves the address, title and chapter rail to the chapter being read; without scripts the « next chapter » card links on. Old single-page anchors (`#r7`, `#people`, …) are redirected from the cover. It is listed in Projects through `react-site/src/content/en.js` and in the sitemap. `/projects/altitude-design-guide/index.html` is only a redirect to it, kept so the guide's first address still works. The Vite build leaves both in place because `emptyOutDir` is off.
- Paper guide, « Learn Paper with me »: `/projects/paper-guide/index.html` is a self-contained page, not built by Vite, generated by the guide's build script (light theme only; fonts from Google Fonts). It is a general, illustrated guide in fourteen chapters, each with an interactive study, drawn figures (inline SVG), procedures and written-down tutorials, plus a reference, seven books and the 52 sources. Its scripts are inline; the shader gallery and the Warp passes in chapter 9 load `@paper-design/shaders@0.0.81` from jsDelivr at runtime (Apache-2.0) and fall back to still swatches. It uses twelve 64 px columns with 32 px gutters and the same grid switch. `/projects/paper-guide/learn-paper-with-me.pdf` is its print edition (148 pages, printed from the same page with the shaders frozen to stills), linked from the top bar, cover and footer; replace the two files together. It is listed in Projects through `react-site/src/content/en.js` and in the sitemap.
- FDA Catalyst dashboard: `/fda-catalyst.html` is a Vite entry (`react-site/src/dashboards/fda/`), drawn from the Paper file « FDA Catalyst ». The FDA Catalyst API sends no CORS headers, so the page reads a copy of the calendar, `react-site/src/dashboards/fda/snapshot.json`. Refresh it with `node scripts/fda-snapshot.mjs` (from `react-site/`) before a build; the dates are counted from the visitor's day, so catalysts that have passed drop out.
- Two kinds of scarcity dashboard: `/research/vista-vs-vistra/` is a Vite entry (`react-site/src/research/vista-vs-vistra/Dashboard.jsx`) reading `report-data.js`, drawn from the Paper file « Two kinds of scarcity ». Blue is Vistra, slate is Vista Energy.
- Both dashboards share `react-site/src/dashboards/board.css`, `kit.jsx` and `theme.js`: the Poseidon grid system (12 columns, 24 px gutters, glass cards, Inter, one blue).
- Book titles, links, and deterministic 3D presentation values: `react-site/src/content/en.js`
- Layout and behavior: `react-site/src/App.jsx`
- Visual system: `react-site/src/index.css`

Keep profile copy and external links in those canonical files instead of duplicating them in root HTML or documentation. The root HTML and `assets/` directory are generated.

## Local workflow

```bash
cd react-site
npm install
npm run lint
npm run build
```

`npm run build` writes `/index.html`, the compatibility redirect at `/work/index.html`, `/reading/index.html`, `/fda-catalyst.html`, and hashed files under `/assets/` for GitHub Pages. Remove superseded `assets/main-*.js` and `assets/main-*.css` bundles when committing a new build.

## Publishing

Push `main`. GitHub Pages deploys the root build to [enzosimier.com](https://enzosimier.com).
